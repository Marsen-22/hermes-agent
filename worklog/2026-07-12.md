   - `graphify`: GRAPHIFY_OUT / LOG_PATH / SKILL_PATH now point to `~/Desktop/hermes/hermes-agent/llm-wiki/` and canonical skills dir.
4. Added a `/health` route to `graphify/dashboard/plugin_api.py` so the dashboard tile can show status.
5. Killed all stale `hermes dashboard` processes and restarted both dashboards from the canonical repo tree (`~/Desktop/hermes/hermes-agent`).
6. Disabled `mcp_servers.langgraph` in `~/.hermes/config.yaml` (`enabled: false`) because there is no LangGraph API server running at `127.0.0.1:2024`; removed `langgraph` from `plugins.enabled` so its broken tile is no longer shown.
