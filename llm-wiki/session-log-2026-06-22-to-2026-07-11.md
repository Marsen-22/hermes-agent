## Key Lessons (Chronological)

1. **Dual config trees** (June 22) — CLI and daemon read different `config.yaml` paths. Always verify which config the running daemon actually loads.
2. **context_length_cache.yaml** (June 22) — The real routing source of truth, not just `config.yaml`.
3. **TCC permissions** (June 24) — OS-level Privacy & Security dialog is separate from keychain access.
4. **Plugin paths after update** (July 8/10/11) — Hermes updates wipe plugin YAML; always have backups.
5. **Thinking model output** (July 11) — Qwen3 thinking models write to `reasoning_content`; disable with `enable_thinking:false` for 16–40x latency reduction.
6. **RPC overhead for large models** (July 9) — 284B DeepSeek V4 is faster on Mac alone (11.1 tok/s) than via RPC (4.5 tok/s); RPC wins for models that fit across nodes.
7. **state.db recovery** (July 10) — SQLite `.recover` successfully restored 140 sessions / 16,066 messages from corrupted DB.
8. **n8n SSRF strict mode** (July 11) — Blocks localhost; design constraint for MCP integration.
9. **Config hot-reload** (July 11) — mtime-based cache; most settings live without restart, but model/provider changes require restart.
